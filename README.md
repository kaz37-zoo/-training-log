# トレログ v3.2

## 品質改善
- iOS風のフェード、カード出現、チェック、シート、トーストのアニメーション
- 「視差効果を減らす」設定に連動する reduced-motion 対応
- 対応端末での触覚フィードバックとON/OFF設定
- requestIdleCallbackを利用した遅延保存、同一データの重複書き込み抑制
- 表示中タブだけをrequestAnimationFrameで再描画
- Dynamic Typeを妨げない文字拡大と、アプリ内「大きめ」文字
- VoiceOver向けラベル、ライブ領域、スイッチ状態、進捗情報
- 空セッション・不要スナップショットを安全に整理するデータ最適化
- データ使用量表示とアプリ内診断
- ナビゲーションはネットワーク優先＋タイムアウト、静的資産はキャッシュ優先
- オフライン状態表示、復帰通知、定期的な更新確認
- PWAショートカット、言語・カテゴリ・IDのmanifest拡充
- 160項目のQAチェックリスト同梱

## 制約
iPhoneのWebアプリから利用できる触覚APIはSafari/iOSの対応状況に依存します。非対応端末では操作を妨げず無反応になります。
