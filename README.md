# トレログ v2.2.1（デバッグ修正版）

## 修正内容

- 削除した初期種目が再起動後に復活する問題を修正
- 実施曜日を「今日」の上半身メニューへ反映
- 曜日未設定を防止し、既存種目は初期状態で全曜日対象
- 種目の追加・削除・設定変更後も、過去履歴の完了数が変わりにくい履歴スナップショット方式へ変更
- バックアップのバージョン表記を2.2.1へ修正
- 壊れた設定データや不正なバックアップでアプリ全体が停止しないよう検証を追加
- 重量・回数入力を入力中にも保存し、画面を閉じる直前にも即時保存
- 休憩0秒の種目で終了音が鳴る問題を防止
- 種目名・メモ表示のHTMLエスケープを追加
- 今日の対象種目がない場合の空表示を追加

## 更新方法

ZIPを展開し、GitHubリポジトリ直下へ全ファイルを上書きしてください。
「その他」の最下部に「バージョン 2.2.1」と表示されれば更新完了です。
